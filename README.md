# 霓虹弹珠厅

## 安装

```bash
npm install
```

## 本地启动

```bash
npm run dev
```

## Docker 启动

```bash
docker compose up --build
```

## 磁力井

台面中部有左右两处磁力井，默认不供电。打下落靶会给对应的井供电一段时间：

- 上落靶 → 左井，下落靶 → 右井，中落靶 → 两口井一起。

供电后球进入作用范围会被持续拉向井心：吸力按物理子帧逐帧累加到球速上，
不会一帧瞬移、也不会与井心重叠，因此挡板的击球时机仍然有效。球进入井心软核后
由向心弹簧加磁滞阻尼稳住；停留超过约 2.6 秒会被轻轻推出，避免永远困在井里。

进入奖励时两口井的磁力方向对调（吸变推），奖励结束（含失球提前结束）后还原回落靶
决定的方向。暂停期间所有吸力与计时冻结，继续后从停下的位置接着吸。

新增挑战「磁力井打出三次」：球先被井接住，再被挡板打离该井，累计三次即完成。
